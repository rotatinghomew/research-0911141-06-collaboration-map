# 数据口径

works 的 author_ids 是同一作品参与者集合，roles 缺失不代表无贡献。作者是稳定 author_id，affiliations 为带生效起止年的机构关系；双聘可重叠。year 为公开年份，不代表合作起始时间。大型合著和个人作品均保留；同一作品只有一个 work_id，不把重复版本当多项成果。没有人工社群标签。

## 数据版本

`fixtures/data.json` 是可直接导入的一份完整材料，`product.json` 保存页面默认范围。导入必须提交完整对象，不把省略字段解释为删除补丁；以规范化 JSON 的 SHA-256 标识内容，同内容多次导入复用版本。原始记录只追加版本，保存的分析材料始终指向原来版本。

页面中的范围影响当前描述，不回写源数据。`null`、缺记录与实际零不能合并；数据格式问题应在导入时明确报错，而不是生成看似成功的空结果。涉及单位、时间或关系的解释以本文件为准，统计方法和业务决策没有预设结果。

## 结构对比口径

结构对比视图把所选范围内的作品按非重叠连续窗口分组（窗口年数可选 1 至 5），在每个窗口内按贡献定义构建加权署名网络并识别群体。贡献定义三选一：分摊（每个署名对计 1/(n-1)，全篇合计 n/2）、整对（每个署名对计 1，一篇 n 人作品展开为 n(n-1)/2 对）、均摊（全篇合计恒为 1）。不默认任何定义；一篇多人作品不应被当作大量独立合作。群体为确定性模块度贪心分组（单层局部移动），同一数据与定义结果可复现；群体是协作证据的聚类，不是行政划分。

相邻窗口间仅当成员集合的 Jaccard 重叠 ≥ 0.5 才沿用群体标签；合并、分散、新生、消散都记录为结构事件。成员变动大、无法可靠续接的群体启用新标签，不为画出连续曲线强行沿用旧名称。成员流动（群体间流动、新活跃、沉寂）与机构变动分别列出；人员调动不等于新合作。

参照模型保持各窗口作者活跃度（人均作品数）与团队规模（各作品人数）不变，随机重配署名关系，随机种子由数据内容与窗口定义决定，可复现。观察值落在参照分布 P5–P95 之间的指标，偶然连边即可解释，不宜解读为组织变化。跨机构占比只统计窗口内两端机构均有生效记录的权重，各窗覆盖率随结果给出；署名角色缺失不代表无贡献，贡献定义不按角色加权。

## 目录

`collaboration_map/domain.py` 提供现行领域校验和描述并按视图分发，`structure.py` 实现结构对比（窗口、贡献定义、群体识别、延续追踪、成员流动、参照模型与趋势分解），`validation.py` 处理基础引用与数值校验，`service.py` 连接领域操作和材料存档，`storage.py` 负责内容寻址数据与历史记录，`server.py` 提供本地接口。`web/app.js` 使用接口构建交互页面，不自行推导独立口径。
